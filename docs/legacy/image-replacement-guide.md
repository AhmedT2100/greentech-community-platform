## 🔧 Instructions de Remplacement

1. **Télécharger les images** depuis les sites recommandés
2. **Renommer les fichiers** selon la liste ci-dessus
3. **Optimiser les images** (compression pour web)
4. **Remplacer dans le dossier** `img/` de votre projet
5. **Vérifier l'affichage** sur votre navigateur

## 💡 Conseils

- **Cohérence visuelle**: Choisissez des images avec une palette de couleurs similaire (tons verts, bleus, blancs)
- **Qualité**: Privilégiez des images haute résolution et professionnelles
- **Licence**: Vérifiez toujours les droits d'utilisation (préférez CC0 ou usage commercial autorisé)
- **Optimisation**: Compressez les images avec TinyPNG ou Squoosh avant de les uploader
- **Format**: JPG pour les photos, PNG pour les logos avec transparence

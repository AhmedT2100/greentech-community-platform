# Third-party material

The HTML Codex template notice is retained verbatim in `template-license.txt`; its original readme is `template-readme.txt`. Other template copies retain their own license/readme files. Existing footer credits are preserved. These notices do not establish a project-wide license for the integrated application.

Browser dependency versions and original upstream identities are recorded in `package.json` and `package-lock.json`. `scripts/restore-assets.mjs` copies installed npm packages to the original resource layout. Bootstrap, jQuery, jQuery Migrate, jQuery Easing, Ionicons, Isotope, Lightbox, Owl Carousel, Superfish, hoverIntent, TouchSwipe, Waypoints, and CounterUp remain subject to their upstream terms. In particular, Isotope and CounterUp include copyleft licensing considerations; dependency restoration does not relicense them.

PHPMailer is installed with Composer, and its version/source reference is locked in `composer.lock`. Its installed package includes upstream copyright and license information. No bundled dependencies are committed.

Original project images, template images, and existing project/team content are retained. Runtime user uploads are excluded. A source image review did not establish independent ownership or new reuse permissions for those images. Existing names in page content are not inferred to be Git commit authors or contributors.

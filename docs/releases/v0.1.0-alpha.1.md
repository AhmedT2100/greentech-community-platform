# GreenTech Community Platform v0.1.0-alpha.1

Initial source prerelease of the existing GreenTechHub PHP/MySQL application, organized for public development.

Includes accounts, events/reservations, articles and moderation, innovations/categories, complaints, metrics, and a local chatbot proxy. This release preserves legacy module variants and their known integration gaps.

Repository preparation centralizes environment configuration, provides locked PHP/browser dependencies, removes private database rows from SQL, excludes runtime data and generated files, retains original attribution, and documents setup and validation.

Local validation: PHP lint (120 files), JavaScript syntax (18 files), npm installation and clean asset restoration, Composer manifest/lockfile validation, schema import (18 empty tables), environment/SMTP object configuration and HTTP smoke checks. See docs/VALIDATION.md for exact results and constraints.

Known limitations: 21 inherited missing resources; moderate dependency findings in Bootstrap/jQuery; inconsistent account schemas/sessions; no end-to-end verification of authentication, SMTP delivery, chatbot or CRUD flows. Temporary runtime PHP/MySQL and mbstring extensions were unavailable. GitHub CI, when run, validates source/dependency setup, not complete workflows.

This is a source distribution. No executable is attached. Configure private environment settings and install dependencies before local use. No project-wide license is newly granted; retained template and third-party notices still apply.
